## 2. Descripción del proyecto

LiceoMap es un proyecto desarrollado con el propósito de ayudar a estudiantes y profesores dentro del establecimiento educacional.

La idea surge a partir de diferentes situaciones y problemáticas observadas dentro del liceo, especialmente relacionadas con estudiantes que, después del toque de campana, pueden no saber a qué sala deben dirigirse, qué asignatura les corresponde o dónde se encuentra determinado lugar del establecimiento.

A partir de estas situaciones surgió la motivación de crear una herramienta que permita acceder de manera rápida y sencilla a información importante del liceo.

---

## 3. Objetivo general

El objetivo principal de LiceoMap es facilitar la orientación y el acceso a información dentro del establecimiento, ayudando principalmente a estudiantes y profesores a encontrar sus salas y conocer sus horarios.

La aplicación busca entregar información relacionada con:

* Ubicación de las salas.
* Horarios de clases.
* Docentes correspondientes.
* Recreos.
* Horarios de almuerzo.
* Horario de salida.
* Mapa general del establecimiento.

De esta manera, se busca disminuir la confusión que pueden tener algunos estudiantes al momento de dirigirse a sus respectivas salas o actividades.

---

## 4. Inicio del proyecto

El proyecto comenzó aproximadamente el **12 de agosto de 2026**.

Durante las primeras etapas se comenzó trabajando en la estructura y diseño inicial de la página web. Benjamín Garate inició el desarrollo utilizando una plantilla como prototipo, la cual posteriormente fue modificándose y perfeccionándose a medida que avanzaba el proyecto.

Con el tiempo se fueron incorporando nuevos elementos de diseño, código, estilos, animaciones y funcionalidades, buscando que la página fuera más atractiva y funcional para los futuros usuarios.

---

## 5. Desarrollo de la página web

La página web ha ido evolucionando progresivamente desde el primer prototipo.

Inicialmente se trabajó sobre una estructura básica, que posteriormente fue mejorada mediante la incorporación de:

* HTML para la estructura de las páginas.
* CSS para el diseño y la apariencia visual.
* JavaScript para agregar funcionalidades e interactividad.
* MySQL para el manejo de la base de datos.
* Animaciones y diferentes elementos visuales.

Actualmente, uno de los integrantes que más ha avanzado en el desarrollo visual de la página es **Josué Castillo**, quien ha trabajado especialmente en la incorporación de animaciones y mejoras visuales.

El proyecto continúa en desarrollo y se siguen agregando y perfeccionando diferentes funcionalidades.

---

## 6. Desarrollo del mapa

Uno de los elementos principales de LiceoMap es el mapa del establecimiento.

Para desarrollar esta parte del proyecto, el equipo recibió de parte de los profesores de programación un mapa del liceo visto desde una perspectiva superior. Este material sirve como referencia para representar la distribución de las diferentes áreas del establecimiento.

A partir de esta información, el equipo comenzó a desarrollar un boceto del mapa que posteriormente será incorporado al proyecto.

También se ha utilizado inteligencia artificial como herramienta de apoyo para diseñar y modificar algunos elementos visuales del mapa, buscando representar de manera clara la ubicación de las salas, patios y otros espacios.

El objetivo final es que los estudiantes puedan utilizar el mapa para orientarse dentro del establecimiento de manera sencilla.

## 8. Contacto con profesores y autoridades

Durante el desarrollo del proyecto, el equipo tuvo la oportunidad de presentar LiceoMap a profesores del establecimiento.

La recepción del proyecto fue positiva, ya que los profesores consideraron que la propuesta tiene potencial y podría ser de utilidad para la comunidad educativa.

Además, el equipo tuvo una reunión con el director del establecimiento con el objetivo de conversar sobre la posibilidad de obtener información o una parte de la base de datos necesaria para continuar desarrollando el proyecto.

Si bien en esta etapa todavía no se obtuvo acceso a dicha información, la respuesta del director no fue un rechazo al proyecto. Se indicó que primero era necesario avanzar en otros aspectos y demostrar un mayor desarrollo antes de poder considerar la entrega de información.

Esta reunión permitió al equipo comprender que el proyecto tiene posibilidades de continuar desarrollándose dentro del establecimiento, siempre que se sigan cumpliendo las etapas necesarias.

---

## 9. Estado actual del proyecto

Actualmente LiceoMap continúa en etapa de desarrollo.

La página web ya cuenta con una estructura inicial y diferentes elementos de diseño, código y animaciones. El equipo continúa trabajando en mejorar la interfaz y agregar nuevas funcionalidades.

También se encuentra en desarrollo el mapa del establecimiento, el cual será una parte fundamental de la aplicación.

Uno de los principales objetivos de las siguientes etapas es continuar mejorando la aplicación, completar el mapa, organizar la información y avanzar en los requisitos necesarios para que eventualmente el proyecto pueda utilizar información proporcionada por el establecimiento.

---

## 10. Proyección del proyecto

A futuro, el equipo espera que LiceoMap pueda convertirse en una herramienta útil para los estudiantes y profesores del establecimiento.

Se espera continuar desarrollando las funcionalidades de la aplicación, mejorar el mapa, incorporar la información de las salas y horarios y, eventualmente, conectar el sistema con una base de datos que permita mantener la información actualizada.

El proyecto todavía se encuentra en desarrollo, por lo que el equipo continuará realizando mejoras, pruebas y modificaciones antes de llegar a una versión final.

El desarrollo de LiceoMap ha permitido al equipo enfrentarse a diferentes desafíos relacionados con la programación, el diseño, el trabajo en equipo y la creación de una solución tecnológica para una problemática real.
